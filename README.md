# FastFlag Pack by Raka

Kumpulan preset FastFlag Roblox untuk dipasang lewat MasterStrap.

## Isi
- `Basic_Fixlag_Master.json` / `Premium_Fixlag_Master.json` / `Vip_Fixlag_Master.json` — pack utama hasil audit (Basic di dalam Premium di dalam VIP).
- `Extreme_10000.json` — tier Extreme v2.
- `Supreme_22435.json` — tier Supreme, semua flag asli Roblox.
- `original/` — file pack versi awal sebelum audit.
- `BACA_DULU.txt` — catatan penting sebelum memakai tier besar.

## Cara pakai
1. Salin isi file JSON tier yang dipilih.
2. Tempel/impor di editor FastFlag MasterStrap.
3. Mainkan Roblox lewat MasterStrap.
